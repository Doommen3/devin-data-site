# devinoommen.com

Source for [devinoommen.com](https://devinoommen.com), the marketing site for **Oommen & Company** — Devin Oommen's independent data infrastructure, automation, and operations practice. The site presents the practice's services and selected results.

It's a static site served via GitHub Pages from the default branch (custom domain configured through `CNAME`), so any push to that branch publishes the live site.

Built with vanilla HTML and CSS — no framework, no build step.
